# Abbey Bridge Consulting Homebrew tap

Install Necronomicdown beta on Apple Silicon with macOS 15 or later:

```sh
brew install --cask abbeybridgeconsulting/tap/necronomicdown
```

The app is ad hoc signed and is not notarised by Apple. If macOS blocks the first launch, try opening the app, then choose **Open Anyway** in **System Settings → Privacy & Security**. Enable Markdown Reader Preview under **System Settings → General → Login Items & Extensions → Quick Look** if Finder previews are wanted.

See the [download information and VirusTotal report](https://github.com/abbeybridgeconsulting/necronomicdown-releases) and the [release checklist](https://github.com/abbeybridgeconsulting/necronomicdown-releases/blob/main/RELEASING.md). Each release requires updating the cask version, URL and SHA-256 after the DMG has been published and verified.
